# 党政机关公文 Word 模板（15 个法定文种）

本目录收录《党政机关公文处理工作条例》第八条规定的 **15 个法定公文文种**的 Word 模板，版式遵循 **GB/T 9704-2012《党政机关公文格式》** 国家标准。每个模板均为**带范例正文的完整模板**，可作为生成对应文种的起手骨架。

## 文种清单

| 序号 | 文件 | 文种 | 适用情形 |
|---|---|---|---|
| 01 | `01-决议.docx` | 决议 | 经会议讨论通过的重大决策事项 |
| 02 | `02-决定.docx` | 决定 | 重要事项作出决策和部署、奖惩有关单位和人员 |
| 03 | `03-命令（令）.docx` | 命令（令）| 公布行政法规和规章、宣布施行重大强制性措施、嘉奖有关单位和人员 |
| 04 | `04-公报.docx` | 公报 | 公布重要决定或者重大事项 |
| 05 | `05-公告.docx` | 公告 | 向国内外宣布重要事项或者法定事项 |
| 06 | `06-通告.docx` | 通告 | 在一定范围内公布应当遵守或者周知的事项 |
| 07 | `07-意见.docx` | 意见 | 对重要问题提出见解和处理办法 |
| 08 | `08-通知.docx` | 通知 | 发布、传达要求下级执行；批转、转发公文；任免人员 |
| 09 | `09-通报.docx` | 通报 | 表彰先进、批评错误、传达重要精神和告知重要情况 |
| 10 | `10-报告.docx` | 报告 | 向上级汇报工作、反映情况、回复上级询问（上行文） |
| 11 | `11-请示.docx` | 请示 | 向上级请求指示、批准（上行文） |
| 12 | `12-批复.docx` | 批复 | 答复下级请示事项（下行文） |
| 13 | `13-议案.docx` | 议案 | 各级人民政府按法律程序向同级人大或其常委会提请审议 |
| 14 | `14-函.docx` | 函 | 不相隶属机关之间商洽工作、询问和答复问题（平行文） |
| 15 | `15-纪要.docx` | 纪要 | 记载会议主要情况和议定事项 |

## 版式规范

模板严格按照 GB/T 9704-2012 实现：

| 要素 | 规范 |
|---|---|
| 页面 | A4，上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm |
| 发文机关标志 | 方正小标宋简体（回退华文小标宋→宋体加粗），红色，居中 |
| 红色分隔线 | 版头与正文之间，约 1.5pt 红色实线 |
| 标题 | 方正小标宋简体二号（22pt），居中 |
| 主送机关 | 仿宋三号（16pt），顶格 |
| 正文 | 仿宋三号（16pt），首行缩进 2 字，固定行距 28pt |
| 一级标题（一、）| 黑体三号 |
| 二级标题（（一））| 楷体三号 |
| 三级标题（1.）| 仿宋三号加粗 |
| 正文层级 | 一、 →（一）→ 1. →（1），不跳级 |
| 成文日期 | 中文数字，含"〇"（如 二〇二六年三月三十一日） |
| 发文字号 | 六角括号〔2026〕X 号 |
| 落款 | 右侧，发文机关署名 + 成文日期 |
| 版记 | 抄送栏 + 印发栏，黑色细线分隔 |
| 页码 | 仿宋四号（14pt），居中，"— X —"格式 |

## 上行文 / 平行文 / 下行文差异

- **上行文（请示、报告）**：版头显示**签发人**（姓名），供上级机关审签参考。
- **平行文（函）**：主送不相隶属机关，称"贵局/贵单位"，结语用"请予支持为盼"。
- **下行文（通知、批复、通报、决定等）**：可用版记（抄送/印发栏）。
- **会议文种（决议、纪要、公报）**：通常无主送机关、无版记；纪要末尾列"出席/列席/发送范围"。
- **命令（令）**：单独编号（第 X 号），落款为"机关长 + 姓名"。
- **议案**：发文机关为人民政府，主送同级人大常委会。

## 重新生成

模板由 `scripts/gen_official_templates.py` 生成，如需调整范例文字或版式：

```bash
# 全量重新生成
uv run --no-project --with python-docx python scripts/gen_official_templates.py
# 只重生成一个文种（改版式时快速迭代）
uv run --no-project --with python-docx python scripts/gen_official_templates.py --only 通知
# 自检：注册表 ↔ 正文 spec ↔ 模板文件三方一致
python scripts/gen_official_templates.py --check
```

脚本自带范例数据，不依赖外部资源；文件名与输出目录由
`office_agent.domain.templates` 的文种注册表决定。

## 新增一个文种

见工程根目录的[《新增office模版的说明.md》](../../新增office模版的说明.md)——
只需注册元数据 + 写正文范例两步，文件名、提示词文种清单与结语规范、
工具描述、测试断言都自动派生。

## 模板的两类占位符

| 占位符类型 | 形式 | 位置 | 由谁替换 |
|---|---|---|---|
| **版头固定槽位** | `{{org}}` `{{doc_no}}` `{{signer}}` `{{date_cn}}` 等 | 版头/落款/版记 | `officecli merge` 一次性预填（见下文） |
| **正文范例占位** | `XX`、`XX工作`、`X年X月X日` | 标题/主送/正文范例段 | LLM 用 `set` / `add_paragraph` 编辑替换 |

版头槽位用命名占位便于程序化批量填充；正文保留中文范例是为了给 LLM 参考公文
语体和结构，由 agent 在生成时逐段替换成真实内容。

## 与 office-agent 的集成（已实现）

agent 已内置公文模式，两条路径都可用：

### 路径 1：自动识别（CLI 启动时预推断）

用户需求里出现公文关键词时，`cli/main.py` 自动识别文种并预创建文档：

```bash
uv run office-agent "写一份关于做好2026年夏季防汛工作的通知"
# → 自动识别为【通知】
# → 大纲预览批准后，从 template/word/08-通知.docx 复制并预填版头占位
# → 启用公文模式系统提示词，agent 编辑正文范例文字
```

文种识别（`office_agent.domain.templates.detect_doc_type`）覆盖注册表里全部文种的关键词，

上行文（请示/报告/议案）优先级最高，批复对"请示"做特殊优先处理。
未命中关键词（如"项目周报""调研报告""Excel 表格"）走普通生成流程。

### 路径 2：LLM 主动调用（start_from_template 工具）

agent 工具集新增 `start_from_template(doc_type, org, doc_no, signer, date_cn)`，
LLM 可在任何时候显式从指定文种模板创建文档（替代 `create_doc`）。例如用户
先说了模糊需求、后补充"要写成通知"，LLM 可调用此工具切换文种。

### 公文模式工作流

1. **文档已就位**：`_prepare_official_doc` 或 `start_from_template` 已用 `merge` 把模板复制到
   输出路径并预填版头槽位（发文机关/字号/日期等）。
2. **agent 编辑正文**：`view_text` 查看结构 → `add_paragraph` 追加真实内容 /
   `remove` 删范例段 / `set` 改具体段落 → `view_text` 自查。
3. **规范保留**：版头红字、红色分隔线、版记、页码由模板承载，agent 不重建。
4. 系统提示词（`_OFFICIAL_BRANCH`）指导 LLM 遵守层级序号（一、→（一）→ 1.）、
   结语用语（通知→"请认真贯彻执行"、请示→"妥否，请批示"等）、上行文签发人等规范。

### 关键模块

| 模块 | 作用 |
|---|---|
| `src/office_agent/domain/templates.py` | 文种注册表（唯一数据源）、关键词识别、merge 数据构造、注册表自检 |
| `src/office_agent/tools/common.py::start_from_template` | LLM 工具：从模板创建文档（含 title/addressee 引导） |
| `src/office_agent/tools/doc.py::update_paragraph` | LLM 工具：整段重写（改标题/主送/某段） |
| `src/office_agent/tools/doc.py::replace_text` | LLM 工具：子串替换，**保留字体**（正文占位编辑首选） |
| `src/office_agent/tools/doc.py::remove_paragraph` | LLM 工具：删范例段 |
| `src/office_agent/office/runner.py::merge_template` | officecli merge 封装（版头槽位预填） |
| `src/office_agent/office/doc.py::DocTool.find_replace` | 底层：保格式的子串替换 |
| `src/office_agent/agent/prompts.py::_OFFICIAL_BRANCH` | 公文模式系统提示词（含编辑工作流+公文规范，结语清单由注册表渲染） |
| `src/office_agent/cli/ui.py::_prepare_official_doc` | 启动时文种识别 + 预创建 |
